# 2.1.6 Decisões de projeto e segurança

| Decisão                                                   | Justificativa                                                             |
| --------------------------------------------------------- | ------------------------------------------------------------------------- |
| Spring Boot em camadas (controller, service, repository). | Separa o HTTP, a regra de autenticação e o acesso ao banco.               |
| SQLite em arquivo local.                                  | O sistema só lê uma tabela de usuários; não precisa de servidor de banco. |
| Senha guardada com BCrypt.                                | Hash com salt: se o banco vazar, as senhas não ficam expostas (RNF02).    |
| HTTPS no Spring Boot (`server.ssl`).                      | As credenciais não trafegam em texto pela rede (RNF01).                   |
| Mesmo erro 401 para usuário inexistente e senha errada.   | Não revela se o login existe (RNF03).                                     |
