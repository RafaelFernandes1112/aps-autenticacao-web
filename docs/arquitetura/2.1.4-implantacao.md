# 2.1.4 Visão de implantação

A Figura 6 mostra onde cada contêiner roda, usando o ambiente descrito na Seção 1.

Figura 6 – Diagrama de implantação (C4). Arquivo: `diagramas/c4-4-implantacao.drawio`.

O usuário chama a API diretamente por HTTPS. No servidor fica uma única aplicação Spring Boot (um `.jar` executado com Java 21) com a API de Autenticação, que atende `POST /api/login`. O HTTPS é configurado no próprio Spring Boot, pelas propriedades `server.ssl`. O banco é um arquivo SQLite na mesma máquina, lido diretamente pela API, sem servidor de banco separado.
