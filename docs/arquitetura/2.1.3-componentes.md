# 2.1.3 Visão de componentes

A Figura 5 mostra os componentes da API de Autenticação. A requisição chega pelo servidor embutido do Spring Boot, entra pelo AuthController e desce até o banco. Classes, fluxo e modelo de dados ficam na Seção 2.2 ([2.2-desenho-detalhado.md](2.2-desenho-detalhado.md)).

Figura 5 – Diagrama de componentes da API (C4, nível 3). Arquivo: `diagramas/c4-3-componentes.drawio`.

| Componente     | Responsabilidade                                                                       |
| -------------- | -------------------------------------------------------------------------------------- |
| AuthController | `@RestController` que atende `POST /api/login`, valida os campos e devolve 200, 400 ou 401. |
| AuthService    | `@Service` que busca o usuário e confere a senha.                                      |
| UserRepository | Consulta o usuário por login ou e-mail no SQLite com `JdbcTemplate`.                   |
| PasswordEncoder | Confere a senha com o hash usando BCrypt (`BCryptPasswordEncoder`).                   |
