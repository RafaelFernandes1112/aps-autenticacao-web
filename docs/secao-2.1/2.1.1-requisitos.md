# 2.1.1 Requisitos do domínio de autenticação

O software recebe credenciais, verifica se pertencem a um usuário válido e devolve a identificação do usuário em caso de sucesso. Ele faz somente a verificação de credenciais.

Figura 3 – Diagrama de contexto (C4, nível 1). Arquivo: `diagramas/c4-1-contexto.drawio`.

## Requisitos funcionais

| Id   | Requisito                                                                                                         |
| ---- | ----------------------------------------------------------------------------------------------------------------- |
| RF01 | O sistema deve receber as credenciais do usuário: login ou e-mail, mais a senha.                                  |
| RF02 | O sistema deve verificar se existe um usuário cadastrado com o login ou e-mail informado.                         |
| RF03 | O sistema deve comparar a senha informada com a senha registrada para esse usuário.                               |
| RF04 | O sistema deve considerar o usuário autenticado somente quando o usuário existir e a senha conferir.              |
| RF05 | O sistema deve devolver a identificação do usuário (`id`, `nome`) quando a autenticação for bem-sucedida.         |
| RF06 | O sistema deve devolver um erro de autenticação quando o usuário não existir ou a senha estiver errada.           |

## Requisitos não funcionais

| Id    | Requisito                                                                                          |
| ----- | -------------------------------------------------------------------------------------------------- |
| RNF01 | O sistema deve receber as credenciais somente por HTTPS.                                           |
| RNF02 | O sistema deve guardar a senha como hash com salt, nunca em texto.                                 |
| RNF03 | O sistema deve devolver a mesma mensagem de erro para usuário inexistente e para senha errada.     |
