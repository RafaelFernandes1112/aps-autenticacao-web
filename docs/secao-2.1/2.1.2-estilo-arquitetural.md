# 2.1.2 Estilo arquitetural e visão em camadas

A arquitetura é descrita com o modelo C4 (BROWN, 2026), que mostra o sistema em níveis: contexto (Figura 3), contêineres (Figura 4), componentes (Figura 5) e implantação (Figura 6).

O estilo adotado é **cliente-servidor em camadas**. O navegador é o cliente, e o servidor é uma aplicação Spring Boot dividida em camadas com responsabilidades separadas. O front-end é escrito em TypeScript e o back-end em Java. Esse estilo é suficiente porque o sistema tem uma única operação, o login.

Figura 4 – Diagrama de contêineres (C4, nível 2). Arquivo: `diagramas/c4-2-conteineres.drawio`.

| Contêiner           | Tecnologia                         | Responsabilidade                                                            |
| ------------------- | ---------------------------------- | --------------------------------------------------------------------------- |
| Aplicação Web       | HTML + TypeScript                  | Formulário de login; envia as credenciais com `fetch` e mostra o resultado. |
| API de Autenticação | Java + Spring Boot                 | Entrega a página de login, verifica as credenciais e responde.             |
| Banco de Dados      | SQLite (arquivo local)             | Guarda os usuários.                                                         |

| Camada       | Onde fica                       |
| ------------ | ------------------------------- |
| Apresentação | Aplicação Web                   |
| Aplicação    | AuthController                  |
| Domínio      | AuthService e PasswordEncoder   |
| Persistência | UserRepository e Banco de Dados |
