## 1.2 Navegador (browser)
 
O navegador é o software de apoio executado no dispositivo do usuário que serve de interface entre ele e a aplicação Web. Ele é invocado por uma ação do usuário, como digitar o endereço da aplicação, seguir um link ou enviar um formulário, e, a partir dela, conduz toda a comunicação com o servidor (MOZILLA, 2026a).
 
Quando o usuário acessa o endereço da aplicação, o navegador interpreta a URL, obtém o endereço IP do servidor por meio do DNS (item 1.3) e estabelece uma conexão TCP protegida por TLS, validando o certificado digital apresentado pelo servidor (item 1.4). Em seguida, envia uma requisição HTTP GET e recebe como resposta os arquivos da tela de login, em HTML, CSS e JavaScript. A partir deles, o navegador constrói a árvore do documento (DOM) e a árvore de estilos (CSSOM), combina as duas na árvore de renderização, calcula a posição e o tamanho de cada elemento (layout) e desenha a página na tela (paint), deixando o formulário pronto para uso (MOZILLA, 2026a).
 
Ao clicar em "Entrar", o código JavaScript da página lê o e-mail e a senha digitados e monta uma requisição HTTP POST para o endpoint /login, com as credenciais no corpo em formato JSON e o cabeçalho Content-Type: application/json, conforme o contrato definido no item 2.1.5. A requisição é enviada pela mesma conexão segura, de modo que as credenciais trafegam cifradas entre o navegador e o servidor (KUROSE; ROSS, 2021).
 
O resultado do processamento depende do código de status da resposta. Em caso de sucesso (200 OK), o navegador recebe o objeto com a identificação do usuário e atualiza a interface para o fluxo autenticado. Se o servidor enviar um cookie de sessão pelo cabeçalho Set-Cookie, o navegador o armazena e passa a enviá-lo nas requisições seguintes ao mesmo domínio, respeitando os atributos definidos pelo servidor: Secure, que restringe o envio a conexões HTTPS; HttpOnly, que impede a leitura do cookie por scripts da página; e SameSite, que evita seu envio em requisições originadas de outros sites (MOZILLA, 2026b). Em caso de falha (401 Unauthorized), o navegador exibe ao usuário a mensagem genérica de erro de autenticação. Assim, o navegador produz dois tipos de resultado: as requisições HTTP enviadas ao servidor e a página renderizada que o usuário vê (ANTHROPIC, 2026a).
