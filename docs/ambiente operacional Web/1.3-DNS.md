## 1.3 Resolução de nomes (DNS)
 
O DNS (Domain Name System) é o serviço que traduz o nome de domínio da aplicação, legível por pessoas, no endereço IP do servidor, que é o que a rede utiliza para encaminhar os pacotes. Trata-se de um banco de dados distribuído e hierárquico, mantido por uma rede mundial de servidores de nomes, que nenhuma aplicação consulta diretamente: o navegador recorre a ele de forma transparente para o usuário (KUROSE; ROSS, 2021).
 
A resolução é invocada pelo navegador sempre que ele precisa abrir uma conexão com um nome de domínio cujo endereço ainda não conhece, como no primeiro acesso à tela de login (item 1.2). O navegador verifica primeiro o próprio cache e, em seguida, repassa a consulta ao sistema operacional, que também mantém um cache e um arquivo local de mapeamentos (hosts). Se o endereço não for encontrado nesses locais, o sistema operacional envia uma consulta, normalmente por UDP na porta 53, ao servidor DNS recursivo configurado na rede, em geral o do provedor de acesso (MOCKAPETRIS, 1987b).
 
Caso o servidor recursivo também não tenha a resposta em cache, ele percorre a hierarquia do DNS em nome do cliente. Primeiro consulta um servidor raiz, que indica os servidores responsáveis pelo domínio de topo (por exemplo, .br); estes indicam os servidores autoritativos do domínio da aplicação; e o servidor autoritativo, por fim, devolve o registro procurado, do tipo A para endereços IPv4 ou AAAA para endereços IPv6 (MOCKAPETRIS, 1987a). O servidor recursivo repassa a resposta ao sistema operacional, que a entrega ao navegador.
 
O resultado do processamento é o endereço IP do servidor web, acompanhado de um tempo de validade (TTL) que determina por quanto tempo cada nível pode mantê-lo em cache, o que torna os acessos seguintes mais rápidos. Com esse endereço, o navegador abre a conexão TCP e o canal seguro descritos no item 1.4. Se o nome não existir, a consulta retorna um erro (NXDOMAIN) e o navegador exibe uma página de falha, sem que nenhuma requisição chegue ao servidor da aplicação (ANTHROPIC, 2026a).
